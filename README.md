# John Veliz — academic website

A lightweight, responsive static website for GitHub Pages.

## Publish

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages** and deploy from the `main` branch at `/ (root)`.
4. Replace `YOUR-USERNAME` here as needed; no build step is required.

## Files

- `index.html` — content and page structure
- `styles.css` — visual design and responsive layout
- `script.js` — automatic copyright year
- `assets/john-veliz-senior-thesis.pdf` — thesis PDF, if copied successfully
- `.nojekyll` — tells GitHub Pages to serve the site as plain static files

## Customize

Add email, CV, GitHub, or other links in the header or footer. The site intentionally avoids a portrait so it works immediately without image assets.
